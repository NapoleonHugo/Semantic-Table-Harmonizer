# Semantic-Table-Harmonizer
异构归一，一个用于同层级异构多表格合并的智能化工具，通过模糊匹配、AI语义分析等方式实现同变量、不同民的数据整理。Semantic-Table-Harmonizer, an intelligent tool for same-level heterogeneous multi-table merging that enables data consolidation for identical variables under different names through fuzzy matching, AI-driven semantic analysis, and related techniques.
