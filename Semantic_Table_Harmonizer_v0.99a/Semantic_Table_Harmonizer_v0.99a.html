《Semantic_Table_Harmonizer》操作手册与方法论指南

四步操作流程、实用提醒及冲突与歧义处理核心逻辑

1

四步核心操作方法

步骤 1：选定数据源

支持拖入整个文件夹、多选 `.xlsx / .xls / .csv` 表格，或点击右上角「下载异构演示数据」直接载入内置的 3 套实证调查数据集。若某份表格的表头不在第 1 行，可在文件卡片右上角点击 `H1 ↑↓` 切换表头所在行。

步骤 2：设定提取变量与列序

增删您需要提取的目标标准变量，上下拖拽卡片调整导出后的列顺序。在底部可点选标记「高层次变量」（如混合效应/多水平模型建模中常见的行政地区、年份、调查波次等高层次变量；当您的表格文件名对应的就是高层次变量且表内未单独设列时，系统会自动从表格文件名直接抓取对应值进行填充）。

步骤 3：泛化变量名与语义辨析

提供模糊匹配泛化（黑）、AI 狭义泛化（蓝，严谨直系同义）、AI 广义泛化（紫，概念扩展）与AI 语义与歧义辨析。进入下一步前支持人工核验与AI 终检，并可将配置好的泛化方案存入右上角「规则库」。

步骤 4：匹配矩阵核验与合并导出

直观展示每份表格对各目标变量的命中状态（精确原名、泛化词命中、文件名提取或缺失）。若有缺失列，可一键点选未匹配表头补充映射或点击「AI全局重匹配与分析」执行重匹配并诊断未匹配原因，最后导出合并后的 `.xlsx` 或 `.csv`。

2

冲突与歧义处理核心逻辑简述

多源异构表格合并中最常见的错误是不同层级的变量互相抢占表头或概念相近但口径正交的变量混为一谈。本工具内置了覆盖社会学、人口学、统计学、经济学等 13 大核心变量族的通用判别准则：

① 嵌套型混淆：上下位层级与总分包含关系

当工作集中同时存在宽泛上位（或总额）变量与具体下位（或分项）变量时（例如：「所属单位/地区」与「省/市」、「家庭年收入」与「工资性收入」、「家庭总支出」与「医疗/教育支出」、「家庭人口数」与「未成年子女数」），上位变量默认的泛化词极易越界包含下位变量。

处理逻辑：系统实行「单向越界追责 + 下位核心同义词豁免保护」（绝不误伤「省」下的“省份”或「工资性收入」下的“劳动报酬”）。您只需在变量卡片上点击「+ 设定/收窄释义」（或运行 AI 辨析），将上位变量收窄为互斥余集（如“地市或区县级行政区（不含省级）”）或明确为“全口径汇总（不匹配单一分项列）”，即可彻底消解冲突。
② 部分重叠型混淆：跨维度语义交叉与正交异义拦截

当两个变量在不同分类轴上存在部分交集或共用复合表头（如「常住地」与「户籍地/出生地」、「受教育程度（既定学历）」与「在读教育学段/受教育年限」、「地理行政区」与「城乡二元分类」），或同一变量内混入了相差 10000 倍的「万元」与「元」。

处理逻辑：内置 26 组学科正交防混淆规则库与量纲一致性检测。一旦混入异义词或跨轴复合词（如同时存在「省」和「市」时混入模糊词“所属省市”），会精准标红该越界词条并提供一键剥离。若反复泛化后仍存在大量冲突，系统会自动弹出深度混淆诊断并提供「⚡ 一键收窄上位变量并净化冲突」。

实用提醒与跨版本持久化说明

  • 本地智能与大语言模型协同：即使未配置 API Key，内置的 13 大分类学词库与本地正交引擎也能独立完成常规泛化、冲突检测与释义收窄；配置 DeepSeek / Kimi / 通义千问 / GLM 等大模型后，可极低成本处理非标准、高度口语化的疑难异构表头。
  • API 配置与规则库跨版本永久保留：您的 API Key、自定义提示词以及保存在「规则库」中的所有泛化方案均存储在独立于版本号的永久存储区中，后续工具版本升级会自动无缝继承，无需重新配置。
  • 人工终检不可替代：科学实证研究对变量口径要求极高，建议在步骤 3 进入步骤 4 的核验窗口中，结合 AI 终检与人工审阅确认无误后再导出最终数据。
